03 / AI PROJECT
独立项目 · AI 辅助开发 · 持续迭代

ACG Trend Radar

动漫游戏热点追踪系统

从内容研究与 IP 选题的需要出发，我尝试将对动漫游戏市场的关注， 转化为可持续记录、比较与追溯的数据观察。 项目目前以动漫数据为起点，逐步建立热度分析与 IP 信息管理的后端原型。

查看代码与开发记录 ↗
01 / 数据观察

热度与历史记录

已编写 AniList 动漫数据采集、热度评分、排行榜和历史快照接口， 为比较不同时点的市场信号建立基础。

02 / 变化分析

关注正在发生的变化

已编写24小时与7天窗口的热度变化分析、变化排行榜及 Rising Radar 接口， 用于探索值得进一步关注的上升信号。

03 / IP 信息

连接作品与事件

已建立 IP 实体、数据源映射与事件管理接口， 并加入广电总局动画备案记录的列表及详情查询接口。

我的工作方式

独立提出问题、拆分需求，使用 AI 辅助编程推进实现， 并在开发中学习数据结构、接口设计与验证方法。 项目通过逐步迭代，将最初的热点观察想法转化为可检查的代码。

技术与自动化

Python · FastAPI。已配置 GitHub Actions 每日执行 AniList 快照采集任务，通过仓库密钥提供数据库连接。

当前展示为开发中的后端原型。热度评分与变化分析描述当前及历史信号； 未来6—12个月的趋势分析仍是研究方向，尚未形成经过验证的预测能力。
